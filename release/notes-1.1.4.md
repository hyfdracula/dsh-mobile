# v1.1.4

手机端（鸿蒙 `com.dsh.mobile`）+ 本机 DSH 插件 `@deepseek-ai/dsh-mobile` 的一批功能与打磨。

## 客户端

- 会话列表回到原生卡片：不透明底、状态色淡底细边，去掉自绘按压缩放与入场滑动；四色状态灯（进行中蓝 / 已完成绿 / 中断红 / 等你回答黄），看过的通知自动消色。
- 待发送候选板：CubeAgent 风格卡片，六点手柄长按拖动排序，每行「立即 / 编辑 / 删除」；图片单独贴在输入框上方，带删除角标，点击全屏预览。
- 题卡：多题逐题排队（第 N / M 题 + 进度条 + 上一题 / 下一题），多选题勾满后点「提交」。
- 聊天页：Markdown 有序列表按原编号渲染；助手气泡顶部只留图标 + 状态/用时，底部「复制 / tokens / 分支 / 完成时间」；图片消息可点开全屏。
- 主界面：选择模型与上下文改成从底部升起的系统半模态（暖金玻璃、左侧标题 + 右侧控件）；设置页统一首页设计语言（浮动标题、渐变、彩色图标、玻璃返回钮），二级页隐藏浮动底部菜单。
- 输入区：三行自适应，进入会话先读本地缓存铺屏（`files/msgs`，最多 60 个会话 × 40 条），失败时不再直接糊红字。
- 设置：新增「存储空间」页（环形占比 / 设备可用 / 分类明细 / 清理缓存）、「通知」页（测试通知、清除未读提醒、直达系统通知设置）、「谁来回答提问」（手机为主 / 电脑为主）、底部版本号读应用包信息。

## 插件

- 统一 outbox（文字 + 图片 + 文件合成一条 prompt）、队列缩略图与 `/queue/reorder` 重排、`/queue-image` 供缩略图直链。
- 归档走宿主 `stopActivity`（运行中的会话也能归档）、`/fork` 分叉、助手回复携带 `turn`（状态/用时/tokens/完成时间/finishedAt）。
- 选择题接管：`user-questions/request` 抢链首、合成 callId、手机在场才接管、桌面为主时立即放行。
- `agentTeams` 开关、`/team` 团队视图、`/goal` 目标控制（查看 / 修改 / 暂停 / 继续 / 完成）。
- `/api/answer-mode` 与 `/api/presence` 心跳（手机在线即接管，离线交桌面）。
- 宿主聚合端点：`/api/host/plugins`、`/api/host/schedules`、`/api/sessions/<id>/fs`（列目录 / 读文本 / 读图片，带 cwd 三级兜底）。

## 安装

```bash
hdc install -r release/dsh-mobile-1.1.4-signed.hap
```

已签名包用的是开发者本机调试证书，profile 里的 UDID 列表不含你的手机，换机可能验签失败；装不上就用自己的证书重签（见 `release/README.md`）。安装包不含任何服务器地址或令牌，首次启动直接进配对向导。
