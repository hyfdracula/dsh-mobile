# v1.1.15

## 扫码连不上：手机现在会自动换备选地址

之前二维码里只放**一个**地址（优先局域网），手机连不上它就直接报错。多网卡的电脑很常见：
Clash / VirtualBox / Hyper-V / WSL 都会多出网卡，排第一的那个手机可能根本到不了。

- 插件侧的二维码现在带备选：`dshmobile://pair?b=<首选>&c=<码>&a=<其它网卡>&a=<公网隧道>`。
- 手机按顺序试，**只有真的连不上才换下一个**；对面一旦答复（码错 / 被拒 / 限流）就立刻停下，
  不会拿同一个一次性码去撞别的服务器。
- 全部失败时给出可执行的排错提示：同一个 Wi-Fi、电脑防火墙放行 DSH（端口 8901）、或者让电脑
  打开公网访问重新扫一次。

插件侧这条要**重启宿主**才生效（本次已随 1.1.15 一起重新构建）。

## 气泡里的蓝字改成黑字

助手气泡里行内代码（`反引号` 那种）和列表的点、序号原来是主题蓝，现在统一成正文黑，
只保留等宽字体做区分。错误卡上的按钮仍是主色，那是可点的操作，不是正文。

## 插件独立发布（可选）

插件现在单独发布成 `dsh-mobile-connect`，可以按仓库或 npm 名安装，不再和别家同名的
`dsh-mobile` 混淆：

```bash
dsh plugin --profile <profile> add github:hyfdracula/dsh-mobile-connect
```

详见 https://github.com/hyfdracula/dsh-mobile-connect 。手机 App 仍然可以从本发布页拿 HAP，
插件包 `dsh-mobile-plugin-0.1.0.zip` 也保留在这个发布页里（离线安装用，已带二维码依赖）。

## 安装

- 手机：下载 `dsh-mobile-1.1.15-signed.hap` 安装（覆盖安装即可，配对信息不会丢）。
- 电脑：插件已装过的，重启 DSH 即可；没装过的，用上面的仓库命令或发布页 zip。
