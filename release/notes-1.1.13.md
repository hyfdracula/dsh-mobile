手机端：

1. 上下文面板的数字不再离谱
   - 根因：插件把「这一轮读了多少」记成了 usage.inputTokens，而这个字段只是没命中缓存的那一小段；命中缓存的大头在 cacheReadTokens 里。所以面板上出现过「系统与工具 163 / 0.0%」「消息 374.4K / 100%」，气泡脚注也只有几百 token。
   - 现在 tokensIn = inputTokens + cacheReadTokens，就是这一跳真实的 prompt 大小。
   - 以当前这个会话为例：系统与工具从 163 变成 329.4K，消息部分 = 上下文 387.2K 减掉这个基线 ≈ 57.8K，两行加起来正好等于上下文合计。
   - 首轮基线不可信（为 0 或大于当前上下文）时，改成一整行「全部上下文」，不再画 0.0% 的假行。
   - 注意：这一条要等电脑端 DSH 重启、插件重新加载之后才会生效。

2. 新手教程按实际流程重写
   - 第一步的安装命令换成真的能用的：dsh plugin --profile desktop add link:<插件目录>（原来写的是插件名，照做装不上）。插件包作为本次发布的第二个附件提供（dsh-mobile-plugin-0.1.0.tgz），解压后把 <插件目录> 换成解压出来的目录即可。
   - 电脑端面板的位置改成「设置 → 手机连接」，并说明配对码是一次性、用过作废。
   - 「连不上？」里原来的「允许异地配对」是旧叫法，改成面板上真实的开关名「公网访问」。
   - 配对码卡的说明原来是「打开插件面板输入 6 位配对码」，容易误解成在电脑上输；改成「把电脑端面板上显示的 6 位码填到上面」。

安装：把 dsh-mobile-1.1.13-signed.hap 传到手机安装即可（HAP 2,242,736 B，sha256 4e06d34a10b0c801b641548a46deb3e860cc52157607995dd658d9e1b0bd736b）。

电脑端插件（可选，只有在自己电脑上装插件时才需要）：dsh-mobile-plugin-0.1.0.tgz，解压后 dsh plugin --profile desktop add link:<目录>，然后重启 DSH。
