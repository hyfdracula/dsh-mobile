# 3.0.0

- 版本号统一升级至 3.0.0（App `versionCode` 3000000，网关插件 `3.0.0`）。
- 多 Agent 引擎接入：网关与手机端完整支持 DSH、Antigravity（`agy acp`）、Claude Code、Codex、OpenCode；支持按引擎筛选会话、独立工作区新建会话、模型切换、自动重绑与免审批模式。
- 端到端加密：新增 Noise_IK 端到端加密信封（三通道并发防队头阻塞）与主机公钥钉扎。
- HarmonyOS 6 双皮肤与统一液态玻璃体系：支持「沉浸光感」与「经典实色」一键切换；顶部胶囊、展开菜单、半模态卡片（模型选择、上下文统计、分组方式、选择电脑、远控工作台）与底部沉底按键/输入框统一高通透实时磨砂玻璃质感。
- 图标与冷启动焕新：新增单色 `>_<` 分层图标（默认浅底深字，设置页支持切换深底白字桌面图标）与无边框冷启动透明标识。
- 聊天交互与体验修复：用户发送气泡统一四圆角并按短消息自适应收窄；修复下拉到底部与输入框间留白过大问题；修复列表左滑按钮重影。
- 局域网稳定性与 ACP 历史修复：放宽局域网探测与连接超时、过滤 VPN 网卡刷新抖动噪音、引入两连失败容错与无感切换；修复 Antigravity 会话并发预拉踩空历史与子进程重启后静默无回复问题。
