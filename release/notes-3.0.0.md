# v3.0.0（自 v1.1.17 以来的完整更新说明）

版本区间：`v1.1.17`（2026-11-22） -> `v3.0.0`（2026-11-26）  
版本号统一升级至 **3.0.0**（鸿蒙客户端 `versionCode 3000000`，桌面网关插件 `dsh-mobile-connect@3.0.0`）。

---

## 一、多 Agent 引擎统一远控（客户端 + 网关）

- **多后端引擎接入**：在原有 **DSH** 基础上，新增 **Antigravity（`agy acp`）**、**Claude Code**、**Codex**、**OpenCode** 统一适配层，手机端可按引擎筛选会话、新建会话时自由指定引擎与电脑工作区目录。
- **Agent 引擎与控制台管理**：设置页新增引擎总览，支持一键刷新探测电脑已安装的 CLI 版本、独立开关各引擎以及一键授权打开桌面端网页控制台。
- **Antigravity 专项优化**：自动探测 `%LOCALAPPDATA%\agy\bin` 等安装路径；开启 `--dangerously-skip-permissions` 与 ACP 权限自动放行避免反复弹审批；修复并发预拉踩空历史记录、子进程退出后静默无回复及增量消息过滤问题。

## 二、Noise_IK 端到端加密与安全加固

- **端到端加密通道（E2EE）**：客户端与网关完整实现 `Noise_IK_25519_ChaChaPoly_SHA256` 加密信封，支持 3 条并发加密通道消除公网队头阻塞，支持主机公钥钉扎、异常换钥拦截与设备管理/撤销，兼容旧宿主回退。
- **凭据与直链加固**：访问令牌与加密私钥迁移至系统受保护存储（Asset Store，支持主令牌与多电脑隔离别名）；图片、工作区原图与文件下载全面改用短期签名链接，移除 URL 长期令牌回退；收紧工作区文件读写的 `realpath` 边界检查。
- **合规与诊断**：新增首次启动隐私与用户协议确认、内置协议查看浮层、自动脱敏的连接诊断日志导出以及应用内意见反馈模块。

## 三、远控工作台与会话工作流

- **会话内远控工作台**：新增工作区文件浏览与读写、Git 状态与 Diff 查看、远端交互式终端、电脑本机开发服务端口预览代理、团队协作看板、定时任务管理、电脑端插件及插件参数配置。
- **增强对话体验**：
  - 接入增量 SSE 流式推送（心跳超时自动平滑回退轮询）与离线发件箱（断网落影子、联网自动重发，带幂等键防重复发送）。
  - 支持 `+` 与 `/` 斜杠指令联动、计划模式（Plan Mode）、长期目标（Goal）、权限档位切换、交互式问答/审批卡片、上下文占用环与统计面板、会话内全文搜索、全屏长文编辑器、思考与工具调用轨迹折叠卡片。
  - 支持导出会话日志为 Markdown（`.md`）与完整压缩包（`.zip`）。
  - GFM Markdown 渲染升级：支持多级标题、任务清单复选框、等高网格表格、代码块一键复制、独立公式块与行内链接点击复制。

## 四、HarmonyOS 6 视觉焕新与交互打磨

- **双皮肤与统一液态玻璃体系**：新增「沉浸光感」与「经典实色」双皮肤一键切换。沉浸光感下统一全站高通透材质阶梯——首页与会话顶栏胶囊、选择电脑、分组方式、远控工作台、选择模型、上下文统计、沉底按键与底部对话框均具备一致的实时磨砂折射与边缘高光；首页 `+` 新建按钮与待发送排队抽屉保留高密遮挡防透字。
- **单色 `>_<` 双套分层图标与无边框冷启动**：全新极简 `>_<` 分层图标，默认浅底深字，设置页支持实时切换深底白字桌面图标；冷启动闪屏改用无边框透明 `>_<` 标识，浅/深色启动背景与首页底色无缝衔接。
- **排版与布局修复**：
  - 用户发送气泡统一改为四圆角，并修复短消息被撑到最宽的问题（短消息自适应收窄，长消息自动换行）。
  - 修正聊天列表下拉到底部后，最后一条气泡与输入框之间留白过大的问题。
  - 修复会话列表在多引擎筛选挂载后左滑按钮（置顶/归档）重影覆在卡片上的问题。
  - 补齐折叠屏/宽屏居中限宽适配与轻触觉反馈。

## 五、局域网稳定性与架构重构

- **局域网防断联优化**：放宽局域网连接超时（`5s`）与读取超时（`>=20s`）；`poke()` 探活不再先清空当前有效连接；过滤 VPN 虚拟网卡刷新引起的无效重探噪音；引入两连失败容错（首次瞬时抖动先原址重试，连续失败再降级公网或标记离线），解决静置易断联问题。
- **全面模块化重构**：完成客户端设置子页、聊天子组件、传输与业务 API 分域拆分，以及网关插件多路由与多后端解耦重构，同步修复图片签名过期不刷新、待发送缩略图携带令牌与备份文件打入 HAP 等历史缺陷。

## 安装与升级说明

- **鸿蒙客户端**：下载附件 `dsh-mobile-3.0.0-signed.hap`（仅授权已登记调试设备，其他设备请按 `release/README.md` 使用自有证书重签）。
- **电脑端网关插件（3.0.0）**：
  ```bash
  dsh plugin --profile desktop add dsh-mobile-connect
  # 或直接从插件仓库安装
  dsh plugin --profile desktop add github:hyfdracula/dsh-mobile-connect
  ```
