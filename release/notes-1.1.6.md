# DSH Mobile v1.1.6

## 客户端
- 聊天页：长按气泡弹操作面板（复制文字 / 引用回复 / 助手消息「从这里开新分支」），行内复制、分支按钮移除。
- 列表：新增「分组方式」菜单 —— 按时间（今天/昨天/更早）或按工作区、显示/隐藏已归档、默认全开/打开第一列/全部关闭、全部标为已读；设置本地持久化。
- 通知：点击通知直达对应会话。
- 进会话不再强制跳到底：网络补全时保持当前阅读位置；轮询只在原本就在底部时跟随。
- 输入框超过三行自动滚动，光标不再被键盘埋住；沉底按钮按输入框实际高度上移。
- 局域网自动切换加固：把电脑自报的所有地址都作为候选逐个探测，换 IP、多网卡、换网段都能切回直连。
- 首页「切换电脑」弹层留白与关闭键位置修正。
- 自动化任务面板：任务可暂停、恢复、立即执行、删除（二次确认）。
- 插件面板：直接启用/停用插件（改写 profile 清单，重启电脑端宿主后生效）。
- 三个管理面板顶栏统一为悬浮玻璃返回钮 + 顶部渐变。

## 插件（需重启电脑端宿主后生效）
- `POST /api/host/schedules/<id>/action`（pause / resume / run / delete）
- `POST /api/host/plugins/toggle`
