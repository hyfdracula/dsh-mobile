# DSH Mobile v1.1.5

这版基本全是「用起来顺不顺手」的修补，重点在**换电脑**、**设置页统一**、**下拉刷新**和**局域网自动切换**。

## 换电脑

- 首页右上角新增**圆形电脑图标**（在已归档按钮左边），点开就是「切换电脑」面板：列出所有已配对电脑，当前那台带徽标，点一下立刻切过去（地址、令牌、会话列表一起换）。
- 设置里的「电脑管理」和「连接」合并成一页「电脑」：顶部电脑列表 + 配对码 / 扫一扫 / 新手引导 / 手动添加，下面是「这台电脑」卡片（地址、连接插件、会话数、重新连接、移除此电脑）。

## 界面

- 首页下拉刷新的转圈和小地球**下移到摄像头开孔以下**。之前调不动是因为系统 `Refresh` 的 `offset` 上限只有 64vp，超出按 64 算；现在换成自定义刷新头（转圈 + 「松开刷新 / 正在刷新」）。
- 存储空间页补上顶部渐变，设置里所有二级页的渐变高度统一成 96（和会话列表页一致），滚动内容在浮动标题下淡出。
- 教程「在外网也能用」：右上角「复制全部」改成中文按钮，每张卡片的复制图标挪到命令右侧（不再挤在标题行）。
- 通知页文案精简：标题改「会话结束通知」，去掉副标题和底部说明，状态只看右侧小圆点。

## 局域网自动切换

- 探活超时 1.5s → 800ms，后台重探周期 60s → 15s。
- 新增回前台立刻重选入口：从外面回到家、或刚切完 Wi-Fi，不用等一轮后台探活。
- 局域网探到 401/403 也算「通」：只有网络层失败才判死，避免换令牌后被误锁 60 秒。

## 本地缓存

- 单个会话的消息快照从 40 条提升到 **200 条**，进会话先用磁盘快照铺屏再拉网更新（实测命中 2–5ms）。
- 缓存文件落在应用私有目录 `files/msgs/<sessionId>.json`，最多保留 60 个会话，超出按时间淘汰；「存储空间」里能看到占用并一键清理。

## 安装

- 已签名包：`dsh-mobile-1.1.5-signed.hap`（`versionName` 1.1.5 / `versionCode` 1000150）。
- 覆盖安装即可，不会丢配对信息。

## 服务端插件

- 自 1.1.4 起插件侧没有破坏性改动；本版仅同步了源码与资源，未改动接口。
