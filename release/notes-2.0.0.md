# 2.0.0

- 版本号提升到 2.0.0（versionCode 2000000），与 1.x 分开归档。
- 设置子页全部组件化：连接表单、电脑列表、外观、通知、数据与存储、关于与支持。
- 聊天侧拆分：正文渲染（Markdown）、图片区、待发送板、待发图片、附件菜单、正在输入、导出 Markdown。
- 接口层拆分：ApiTypes、ApiUtil；插件侧拆分 http-util、panel。
- 安全：令牌只存 Asset Store（主令牌 + 每机器别名）；图片/文件直链去掉长期令牌回退；纯图影子按图片消息核销。
- 离线：断网直接落影子、联网自动重发；列表失败时提示「地址可能变了」。
- 修复：图片签名过期后不刷新、待发送板缩略图带令牌、备份文件被打进 HAP。
