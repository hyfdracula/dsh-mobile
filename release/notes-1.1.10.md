# v1.1.10

这一版是上一轮 7 条反馈的修复。

## 修了什么

### 1. 首页小地球（刷新指示器）常驻
上一版（1.1.9）已经修好，这一版把判定再收紧了一次：只有手指真的在往下拖、或者在刷新中，才画那个转圈。

### 2. 「选择文本」切换加了动画，两边动画统一
- 白胶囊不再瞬移，而是从左滑到右（200ms，EaseOut）。
- 正文与 Markdown 原文之间改成交叉淡入淡出，曲线与时长和白胶囊完全一致。
- 分段控件不再各自画底色，改成一个真正的滑块。

### 3. 编辑待发送的右上角改成「取消」
编辑待发送时那个按钮原来写「完成」但并不保存，现在写「取消」并直接关闭、不写入任何内容；编辑草稿时仍显示「完成」（草稿本来就会自动保存）。

### 4. 触感反馈开关的状态
- 开关现在始终显示真实状态：以前只在进页面时读一次，父级改动不会同步过来，离开再回来就可能显示旧值。
- 连续快速开关时，后到的旧写入不会再覆盖新值（写入带序号，过期写入直接丢弃）。
- 反复开关之后打不开的问题一并修掉。

### 5. 删除待发送条目偶发闪退
根因是待发送条目的每一行记的是「渲染那一刻的下标」，删掉一条之后旧行的点击回调还会被触发，于是拿下标去数组里取东西取到空值再读字段，就崩了。
现在所有操作都按条目 id 查、查不到就什么都不做；按下标删除的地方也先做越界检查。

### 6. 设置页图标全部重画
电脑、外观、通知、存储空间四行原来用的是字形字符，字体一换形状就跑、光学也不居中。现在换成四个专门画的矢量图标：显示器、半月、铃铛、叠盘。

### 7. 「自动切换局域网」「谁来回答提问」搬出了公网地址卡片
- 这两块现在各自独立成卡，排在「公网地址」之前，不填地址和令牌也能切换。
- 标题下面那些解释性小字，改成标题后面的小感叹号，点一下弹出解释。覆盖设置里的电脑页、外观页、通知页、添加电脑弹层与会话页的智能体协作；存储空间那一栏保持原样。
