# DSH Mobile 1.1.7

2026-11-22

## 修复用户上报的 9 条

1. 工作区文件可以保存到手机：文件预览页新增「保存」，走系统另存面板，任意类型都能落盘。
2. 主界面不再常驻「小地球」：下拉刷新指示器只在真正下拉或刷新时出现；首屏 6 秒未返回时给出可点的「还没连上电脑 / 点这里重试」。
3. 返回一次就能退出会话：根因是同一个 openSession 键被「当前会话」与「通知直达」共用，点一次卡片压了三层 chat；通知直达改用独立键，返回键显式出栈。
4. 右上角三个点改成与首页分组一致的玻璃弹窗，分「电脑侧 / 会话」两段。
5. 长按消息改为整屏「选择文本」面板：正文 / Markdown 原文切换、复制全部、正文可选中，底部复制全文 / 引用全文 / 开新分支。
6. 进会话不再强制跳到底部：只有用户本来就在底部才跟随新消息；缓存铺屏、图片撑高、待发送板都不再抢滚动位置。
7. 输入框超过三行不再看不到内容：高度随内容增长到六行，超出后在框内滚动且光标保持可见。
8. 局域网切换加固：探针并发且首个成功即返回、超时放宽到 1.5-2 秒、失败后安排后台重探、保存地址不再清空候选、换电脑不把上一台的地址带过去、wanBase 本身就是内网地址时也按直连处理。
9. 出错时在消息流里插一张可复制的错误卡片：显示 code 与完整报错正文，可复制、可收起，不再只闪一条 toast。

## 其它

- 新增 `/api/sessions/<id>/fs/download`：任意文件下载，带真实路径校验，防止符号链接越出工作区；`/fs/file`、`/fs/raw`、`/fs` 同享该校验。
- `/api/sessions/<id>/messages` 增加 `lastErr`，成功的一轮会清掉上一次的报错，避免旧错误在重进会话时又冒出来。
- 通知直达（点通知打开会话）行为不变。
